# CocoVis

Клиентский Fabric-мод для Minecraft 26.3: меню визуалов (Right Shift), панель алмазов, информационная панель, ножи Huntsman.

## Включённые компоненты
- **Natural Motion Blur** 1.4.5 — автор Pasi, лицензия LGPL-3.0. Лежит внутри CocoVis без изменений
  (`META-INF/jars/naturalmotionblur-1.4.5.jar`), текст лицензии находится внутри самого jar. Требует YetAnotherConfigLib.
- **Huntsman Knives** — оригинальные 3D-модели и текстуры CocoVis, встроенный ресурспак.
