# CocoVis 0.0.1 — Overhaul

Клиентский Fabric-мод для Minecraft 26.3.

## Что обновлено
- Полностью переработан экран Visuals: Control Center с боковой навигацией, счётчиками активных модулей, карточками, анимированными переключателями и индикаторами состояния.
- Обновлена палитра интерфейса: глубокий графитовый фон, фиолетовые и синие акценты.
- Сохранены существующие игровые модули, настройки и HUD editor.
- Версия мода установлена на `0.0.1`.

## Сборка
Требуется JDK 25 и Gradle, совместимый с Fabric Loom из `build.gradle`.

```bash
gradle build --no-daemon
```

Готовый JAR появится в `build/libs/`.

GitHub Actions workflow запускает ту же сборку при push или вручную через `workflow_dispatch`.
