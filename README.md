# CocoVis

Клиентский Fabric-мод для Minecraft 26.3: меню визуалов (Right Shift), панель алмазов, информационная панель,
уведомления об алмазах, 3D-нож Huntsman. Версии и изменения — в `CHANGELOG.md`.

## Включённые компоненты и источники
- **Natural Motion Blur** 1.4.5 — автор Pasi, лицензия LGPL-3.0. Лежит внутри CocoVis без изменений
  (`META-INF/jars/naturalmotionblur-1.4.5.jar`), текст лицензии находится внутри самого jar. Требует YetAnotherConfigLib.
- **Huntsman** — геометрия и базовая текстура взяты из пака «CS2 Knifes Pack v1.0.1» (`cs2_wt`) и сконвертированы
  из формата Bedrock в модель предмета Minecraft; цвета четырёх материалов нарисованы заново.
  У пака нет файла лицензии, а исходный дизайн ножей принадлежит Valve, поэтому мод предназначен только для личного
  использования: не публикуй его без разрешения автора пака.
